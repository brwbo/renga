add the chrome extension

a side panel with one team's chat. it reads your tabs or meet calls when the team has an agent for it.

  1. download renga-extension.zip it's set up to talk to this server.
  2. unzip it. you get a renga folder.
  3. open chrome://extensions chrome won't open it from a link, so paste it into the address bar.
  4. turn on developer mode (top right), click load unpacked and pick the renga folder.
  5. pin renga from the puzzle-piece menu, click it, and pick a team.
